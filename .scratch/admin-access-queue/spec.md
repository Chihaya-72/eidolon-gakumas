## 行为

- 新库首位注册用户在同一注册事务中成为持久管理员；旧库首次升级授权最早用户，迁移只运行一次。保留环境变量指定的额外管理员，开发登录不再默认授予所有人管理权限。
- 后台配置增加管理员设置：默认关闭的访问密码、密码修改、浏览器/IP 黑名单和解封。密码以加盐 scrypt 保存。页面和业务 API 都验证通行凭据，30 天有效，开关或密码变化撤销旧凭据。
- 浏览器与 IP 分别累计错误，任一达到三次封禁两者；正确密码清零对应错误。提供服务器恢复命令，并由受控 Caddy 代理覆写客户端 IP。
- 共享主要 API 的用户操作共用一个不抢占服务位：管理员优先、滚动六小时使用次数升序、同次数先进先出。计数独立持久化；校验完成并开始服务才计数。全部主要服务自带密钥则绕过共享队列，辅助判断/检索不影响判断。
- 文字、整通语音、酒吧每次回复、朗读、异步生图进入同一队列。等待调酒不占位；共享照片等待父操作释放服务位；取消、异常和关闭可靠释放。
- 浏览器票据绑定用户、操作和目标资源，语音额外绑定对话。每两秒更新位置，可取消；等待心跳 60 秒，轮到保留 15 秒；语音轮到后才开麦。未携带票据也经过服务队列，实际操作重新验证密钥来源与权限。
