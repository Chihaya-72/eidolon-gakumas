# 管理员公用 API 与无密钥启动

- 公用 API 入口集中到管理员设置，个人自用 API 的表单、存储和校验方式保持不变。
- 对话模型地址、密钥、模型允许在启动时留空；未配置时不请求服务商，不显示为已配置服务。管理员可在启动后配置并持久保存。
- API Key 的数据库持久化仍依赖 EIDOLON_SECRET_KEY 加密，不把密钥写入日志、说明或截图。
- 第一次启用判断模型允许在后台保存，明确提示需要重启来接入相关功能；已运行的判断模型继续支持热切换。
- 公用 API 的 HTTP/SOCKS 路由沿用已有实现，支持自定义公用地址；新增一键选择全部公用服务，个人路由选项不变。
- 已保存的代理在重启检查失败或密码无法解密时仍保留其路线，不回退到直连；启动前的 API 检查先读取后台保存的代理。
- WARP 只接入已在后端机器运行的本地代理，不安装客户端或改变操作系统路由。
- 可选游客登录为每个浏览器保存独立身份，仍需确认条款与通过访问密码，不参与首位管理员授权。
- 网站访问密码保持 8 至 128 个字符；覆盖短密码拒绝与 8 位密码可用的边界测试。
- 验证：无密钥真实 build/serve；保存后重启保留；个人 API 原有测试；代理故障与启动探测不绕行；构建版后台桌面/手机验收。
