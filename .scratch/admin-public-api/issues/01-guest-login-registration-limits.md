# 游客登录没有邀请限制和数量限制

Status: needs-triage

PR #4 审核时发现，维护者决定暂不修复，先记录在这里。

## 问题

`POST /api/auth/guest-login`（`backend/src/eidolon/account_api.py`）直接调用 `store.guest_user`，没有经过 `accounts.sign_in` 里的注册和邀请检查，也没有频率或数量限制。只有 `EIDOLON_GUEST_LOGIN=1` 时才会受影响。

- 注册设为仅邀请时，没有邀请码的访客也能通过游客登录成为新用户。
- 不带 `eidolon_guest` Cookie 反复请求，每次都会新建用户，可以撑大数据库。
- 每个新游客都有独立额度，可以用来重复消耗公用 API。
- 被封禁的游客清掉 Cookie 就能换一个新身份。

访问密码门禁仍然有效，开启后没有通过密码的人不能创建游客。

## 验收标准

- [ ] 明确仅邀请注册时游客登录的行为，并在代码和文档中保持一致
- [ ] 限制游客创建的频率或总量
- [ ] 限制游客可消耗的公用 API 额度，或说明为什么不需要
- [ ] 决定如何处理被封禁游客换身份，并清理长期不用的游客账号
